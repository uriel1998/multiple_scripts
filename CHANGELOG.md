# Changelog

## v0.20.12 - 2026-08-11

### clipimg.sh

- added repeatable `--sticker` overrides so a run can ignore env-defined stickerpacks and use only named packs or arbitrary directories passed on the command line
- added `--no-dragon` to suppress the Dragon drag target while still copying the selected image normally
- updated built-in help and the README to document the current `clipimg.sh` selection and output behavior
